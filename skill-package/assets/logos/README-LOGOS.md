# Logos para Baby's Log - Alexa Skill

Este paquete contiene los logos diseñados para tu skill de Alexa "Bitácora del Bebé" (Baby's Log).

## 📁 Archivos Incluidos

### Diseño Principal
- **babys-log-logo.svg** - Logo vectorial (escalable sin pérdida de calidad)
- **babys-log-logo-108.png** - Ícono pequeño (108x108px) para Alexa
- **babys-log-logo-512.png** - Ícono grande (512x512px) para Alexa

### Diseño Alternativo (Minimalista)
- **babys-log-logo-alt.svg** - Logo alternativo vectorial
- **babys-log-logo-alt-108.png** - Ícono pequeño alternativo (108x108px)
- **babys-log-logo-alt-512.png** - Ícono grande alternativo (512x512px)

## 🎨 Características del Diseño

### Logo Principal
- **Biberón central**: Representa la funcionalidad principal de rastreo de alimentación
- **Ícono de hoja verde**: Representa Google Sheets y el registro de datos
- **Reloj naranja**: Simboliza el seguimiento temporal
- **Marcas de medición**: Indican la precisión del tracking
- **Corazón rosa**: Añade calidez y enfoque en el cuidado del bebé
- **Colores**: Rosa (#FF6B9D), Azul (#4A90E2), Verde (#34A853), Naranja (#FFA726)

### Logo Alternativo
- **Diseño más simple**: Enfocado principalmente en el biberón
- **Gradiente moderno**: Rosa suave que transmite calidez
- **Check verde**: Confirmación de registro exitoso
- **Texto "Baby's Log"**: Identificación clara de la skill
- **Menos elementos**: Más limpio y minimalista

## 📋 Requisitos de Amazon Alexa

Amazon Alexa requiere DOS tamaños de íconos para las skills:

1. **Ícono Pequeño**: 108x108 píxeles ✓
2. **Ícono Grande**: 512x512 píxeles ✓

Ambos tamaños están incluidos en este paquete.

### Especificaciones Técnicas de Alexa
- Formato: PNG
- Fondo: Transparente o de color sólido
- Resolución: 72 DPI o superior
- Espacio de color: sRGB o Adobe RGB
- Tamaño máximo de archivo: 2 MB

## 🚀 Cómo Usar los Logos

### En Alexa Developer Console

1. Inicia sesión en [Alexa Developer Console](https://developer.amazon.com/alexa/console/ask)
2. Selecciona tu skill "Bitácora del Bebé"
3. Ve a **Distribution** → **Skill Preview**
4. En la sección **Icons**:
   - Sube `babys-log-logo-512.png` como **Large Icon** (512x512)
   - Sube `babys-log-logo-108.png` como **Small Icon** (108x108)
5. Guarda los cambios

### En tu Repositorio GitHub

Puedes agregar el logo al README de tu repositorio:

```markdown
<p align="center">
  <img src="docs/logo.png" alt="Baby's Log Logo" width="200"/>
</p>

# Baby's Log - Alexa Skill
```

## 🎯 Recomendaciones

### ¿Cuál logo usar?

**Logo Principal** → Recomendado si:
- Quieres destacar todas las funcionalidades (tracking, Google Sheets, tiempo)
- Prefieres un diseño más completo e informativo
- Tu audiencia es técnica

**Logo Alternativo** → Recomendado si:
- Prefieres un diseño más limpio y simple
- Quieres mayor enfoque en el aspecto "bebé"
- Buscas un estilo más moderno y minimalista

## 📝 Modificaciones Futuras

Si necesitas modificar los logos:

1. **Archivos SVG**: Edítalos con:
   - [Inkscape](https://inkscape.org/) (gratis, open source)
   - [Adobe Illustrator](https://www.adobe.com/products/illustrator.html)
   - Cualquier editor de texto (son archivos XML)

2. **Regenerar PNGs**: Usa el script incluido o herramientas online como:
   - [CloudConvert](https://cloudconvert.com/svg-to-png)
   - [Convertio](https://convertio.co/es/svg-png/)
